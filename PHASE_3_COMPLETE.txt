🎯 DELIVERABLES
────────────────

✅ SIX AUTHENTICATION ENDPOINTS

1. POST /api/auth/register/
   • Register new user account
   • Validates email uniqueness
   • Confirms password match
   • Returns user data and user ID

2. POST /api/auth/login/
   • User authentication
   • Password verification
   • JWT token generation
   • Returns token + user profile

3. POST /api/auth/logout/
   • Client-side token removal
   • Server-side preparation for token blacklisting
   • Confirms logout success

4. GET /api/auth/me/
   • Retrieve current user profile
   • JWT protected endpoint
   • Returns full user information

5. PUT /api/auth/profile/
   • Update user name and phone
   • JWT protected endpoint
   • Validates input
   • Returns updated profile

6. PUT /api/auth/change-password/
   • Change user password
   • Verifies old password
   • Validates new password format
   • JWT protected endpoint

🧪 QUICK TEST GUIDE
────────────────────

1. Start MongoDB:
   docker run -d -p 27017:27017 --name mongodb mongo:latest

2. Initialize database:
   python manage.py init_db

3. Start development server:
   python manage.py runserver

4. Test registration (cURL):
   curl -X POST http://localhost:8000/api/auth/register/ \
     -H "Content-Type: application/json" \
     -d '{"name":"Test","email":"test@test.com","phone":"+1234567890","password":"Pass123","password_confirm":"Pass123"}'

5. Test login:
   curl -X POST http://localhost:8000/api/auth/login/ \
     -H "Content-Type: application/json" \
     -d '{"email":"test@test.com","password":"Pass123"}'

6. Save the returned token and use in next requests:
   curl -X GET http://localhost:8000/api/auth/me/ \
     -H "Authorization: Bearer <your_token>"
